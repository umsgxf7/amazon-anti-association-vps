## 亚马逊判定关联时看哪几样，IP 占多重的分量

平台看的是组合信号：IP 地址、设备指纹（浏览器指纹、时区、字体、Canvas、WebGL）、注册资料（邮箱、手机、信用卡、收款账户）、操作行为习惯，以及产品重叠度。IP 的权重高，因为它是平台最容易直接读到的一项，归属地、运营商、IP 类型三样一次拿全。

机房 IP 在 IP 库里标的是 Hosting 或 Cloud，真正的美国家庭宽带标的是 Residential，运营商显示 AT&T、Comcast 这类名字。同一个账号在机房 IP 上登录，等于告诉平台"这个美国卖家在数据中心办公"。普通 VPN 解决不了这个问题，节点本身也是机房，而且一个出口可能几百人共用。

所以"一号一机一 IP"是底线：一台 VPS 只登一个店，别在 A 店的机器上顺手登 B 店看一眼；新账号从注册第一步就在 VPS 里做，不要先用本地 IP 注册完再切过来；某个 IP 上出过问题的账号，这个 IP 就别再给新号用了。

## 机房 IP、原生 IP、双 ISP、双端独立 IP：四个词别混着用

| 概念 | 说的是什么 | 防的是哪一类关联 |
| --- | --- | --- |
| 机房 IP | 数据中心托管段，IP 库标 Hosting/Cloud | 不防，本身就是风险信号 |
| 原生 IP | WHOIS 归属真实家庭宽带运营商，不是 Hosting | IP 类型被判定为"非居民" |
| 双 ISP | 同一 IP 具备两家运营商的归属特征 | ASN 层面的关联与真实度质疑 |
| 双端独立 IP | 入口和出口各一个独立 IPv4，强调独占 | IP 被他人复用导致的关联 |

前两个好理解，后两个经常被商家混着宣传。双端独立 IP 的核心是"这个 IP 只有你在用"，解决的是复用问题；双 ISP 的核心是"这个 IP 看起来像两家运营商下的居民宽带"，解决的是归属真实度问题。你真正要防的是两个店被算法认成同一个人，所以顺序是先保证独占（一店一 IP），再看 IP 的归属像不像居民宽带。

SixtyNet 页面上只写了 Residential IP，没有写双 ISP，也没有写双端独立。买之前值得问一句：这个 IP 的 WHOIS 归属是哪家运营商，是不是独享。拿到 IP 之后自己做两个动作：去 scamalytics 查欺诈评分，0–5 分属于极低风险；用 Whois 看是不是住宅段，顺手查一遍黑名单。
